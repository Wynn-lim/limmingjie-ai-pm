先判断价值，再决定要不要上 Agent。

一个 Prompt 能解决的事情，不做复杂 Agent。只有涉及多步骤判断、知识来源、跨系统执行或数据反馈时，才提高系统复杂度。

STEP 01
进入业务，梳理当前流程
先把现在怎么做的搞清楚，不急着上工具。
STEP 02
找出高频、重复、耗时、易错的环节
只在真正消耗人的地方动手。
STEP 03
选 Prompt / Skill / Agent / RAG / API / RPA
能用简单方案解决的，不上复杂系统。
STEP 04
先完成最小可用闭环
先跑通一次完整流程，再做扩展。
STEP 05
用效率、质量、成本、使用率验证
没被真正用起来的方案不算落地。
