# 明天怎么讲（一页版）

网站地址：本地 `limmingjie-ai-pm-workbuddy` → 运行 `npm run preview -- --port 4173`，浏览器打开 `http://127.0.0.1:4173/limmingjie-ai-pm/`
（部署后为 `https://<账号>.github.io/limmingjie-ai-pm/`）

## 开场怎么做（30 秒）

1. 打开网站，停在首屏（**不要**打开提词）。
2. 点「**开始15分钟介绍**」→ 自动进入标准模式，右侧出现提词。
3. 之后每次只需要：**看右侧提词 → 讲 → 按「下一节」或空格**。
4. 被追问时点右上角「**对方可能会问**」，答完点「关闭并回到刚才那一屏」。
5. 面试官时间不够时，顶部下拉切「**8分钟精简**」，次要屏会自动隐藏。

## 15 分钟讲解顺序（14 屏）

| # | 屏 | 讲什么 | 建议 |
| --- | --- | --- | --- |
| 1 | 首屏 `s-hero` | 自我介绍 + 四张证据卡 | 1 分 |
| 2 | 岗位匹配 `s-match` | 六项岗位需求逐条对应；主动说真实性边界 | 1 分 |
| 3 | AI落地方法 `s-method` | 五步法；强调「一个 Prompt 能做的事不做 Agent」 | 0.5 分 |
| 4 | 企业AI内容生产体系 `s-content` | 背景、职责、关键结果，点进详情页 | 1.5 分 |
| 5 | 完整工作流 `s-content-flow` | 九步流程 + 100+ 模板 | 1 分 |
| 6 | 账号矩阵 `s-accounts` | 四个账号 + 三条代表作品（讲完不点外链，扫码兜底） | 1 分 |
| 7 | 音响视频 `s-video` | 先放视频，再讲过渡语 | 1 分 |
| 8 | 3C 内容工作流 `s-c3` | **最高权重**：十步流程 + 参数到场景映射 | 1.5 分 |
| 9 | 质检与数据闭环 `s-c3-qa` | 三个 Skill、AI 与人工边界、六项数据指标 | 0.5 分 |
| 10 | AI 编导 Agent `s-director` | 状态是产品 Demo，可进详情页讲 6 个节点 | 1.25 分 |
| 11 | RAG 合规专家 `s-rag` | 状态是产品方案 + 页面 Demo | 1.25 分 |
| 12 | 四个入职项目 `s-projects` | 问题 → 方案 → 步骤 → 数据 → 人工点 → 指标 | 2.5 分 |
| 13 | 30/60/90 `s-plan` | 三阶段计划 | 1 分 |
| 14 | 结尾 `s-closing` | 总结；GEO 只说「提高被引用的概率」 | 0.5 分 |

**8 分钟精简路径**：1 → 2 → 4 → 6 → 7 → 8 → 12 → 13 → 14（隐藏 3、5、9、10、11）。
第 4 章在精简模式下点顶部导航会直接跳进「AI 编导」详情页。

## 三条容易踩的线（必须按这个说）

1. **AI 编导工作台是产品 Demo**：提示词和内容方法用在真实工作里，但整个页面不是公司上线系统。
2. **研发费合规专家是产品方案 + 页面 Demo**：知识库规模、准确率、效率提升都是设计目标，不是上线结果。
3. **神州行只讲 36 个作品和全流程职责**：31 粉丝、237 获赞留在原始截图里，不做数据卡。

## 兜底准备

- 外链打不开：直接说「抖音网页端可能要登录，用二维码扫」，页面已给提示。
- 视频放不出来：页面保留封面和说明，也可点说明里的链接用本地播放器打开。
- 没有网络：站点是纯静态，本地 `npm run preview` 即可完整演示。
